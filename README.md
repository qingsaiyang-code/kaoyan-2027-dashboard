# 2027 考研备考驾驶舱

这是一个个人使用的静态备考规划网站，当前第五版覆盖：

- 仪表盘：倒计时、今日任务、四科进度、本周投入、风险提醒
- 今日计划：新增、完成、删除任务，并按今天/本周/全部筛选
- 科目进度：408、数学一、英语一、政治的章节进度滑块
- 周复盘：记录本周做得好的地方、卡点和下周调整
- 错题本：按科目、知识点、错误类型、优先级记录错题，并追踪是否解决
- 套卷记录：保存真题或模拟卷的得分、满分、用时和考后结论，自动汇总得分率
- 数据备份：从侧栏导出 JSON 备份，也可以导入此前的备份文件
- 复习路线：围绕考试日期划分基础、强化、真题、冲刺四个阶段，并给出四科重心
- 学习记录：单独记录真实专注时长，驱动周投入统计、近 28 天学习日历和周复盘
- 每周目标：可设定每周专注小时数，仪表盘实时显示完成比例
- 逾期处理：任务列表可单独筛选逾期任务，并一键移到今天重新安排
- 目标管理：记录目标院校、专业方向、分数线、资料、各科目标分和投入权重
- 任务细节：每项任务可记录优先级、难度、完成状态和实际用时
- 薄弱点分析：错题保留来源与复习次数，自动聚合未解决的知识点排行
- 模考复盘：记录错题数、总题数、主观评价，查看成绩变化与各科投入/表现

## 使用方式

直接打开 `index.html` 即可使用。

数据保存在当前浏览器的 `localStorage` 中，不需要账号和后端。换浏览器或清除浏览器数据后，本地记录会丢失，因此建议定期使用侧栏的“导出数据”备份。

## 默认设置

考试日期暂定为 `2027-12-25`，可以在左侧栏自行修改。

默认科目：

- 408
- 数学一
- 英语一
- 政治
